World scripting

Make worlds do things: change players, the camera and the world. Scripts are JavaScript, written in the Studio's Scripts tab (Tier 4+).

The two kinds of script

SERVERRuns on the server, once per world, while anyone is inside. It is in charge: it changes players (speed, size, colour, teleport, freeze…) and the world (ground, spawn, objects) for everyone, and keeps scores and rules.
CLIENTRuns in each player's browser. It controls only what that player sees and does: the camera, on-screen UI, key and mouse input, local effects. A client script can never change the world for other players.

The two talk through RemoteEvents, like Roblox: a client asks, the server decides. Never trust the client — anything a player's browser sends can be faked, so check it on the server.

Nothing a script does is saved. When everyone leaves, or you save the world or its scripts in the Studio, the world goes back to its saved layout and the scripts start fresh. Scripts can't touch Seals, accounts or other worlds.

Quick start

// SERVER script
const Collect = Remote.event('Collect');
const CoinsChanged = Remote.event('CoinsChanged');

players.onJoin(player => {
  player.title = 'Newcomer';
  player.setAttribute('coins', 0);
});

Collect.onServerEvent(player => {            // the player who sent it comes first
  const coins = (player.getAttribute('coins') || 0) + 1;
  player.setAttribute('coins', coins);
  CoinsChanged.fireClient(player, coins);
  if (coins % 5 === 0) player.speed = 1 + coins / 20;
});
// CLIENT script
const Collect = Remote.event('Collect');
const CoinsChanged = Remote.event('CoinsChanged');

camera.zoom = 1.3;
ui.text('coins', 'Coins: 0', { anchor: 'top', y: 12, size: 20 });
CoinsChanged.onClientEvent(n => ui.text('coins', 'Coins: ' + n, { anchor: 'top', y: 12, size: 20 }));
input.onKeyDown(key => { if (key === ' ') Collect.fireServer(); });

Basics (both sides)

console.log / warn / errorServer output appears in the Studio's console. Client output appears in the Script output panel when you playtest (admins only) and in the browser console.
setTimeout, setInterval, clearTimeout, clearIntervalNormal timers. Server timers tick 20 times a second, so they are accurate to about 50 ms. Limit 100 timers.
await wait(ms)Pause a script. Every script is an async function, so you can await at the top level: while (true) { await wait(1000); … }
Remote.event(name)Gets (or makes) a RemoteEvent. Names are 1–40 letters, numbers, _ . -. Both sides use the same name.

Server API SERVER

players

players.onJoin(fn)fn(player). Runs for every player, including those already in the world when scripts start (so you don't need a loop).
players.onLeave(fn)fn(player). The player can still be read for a moment.
players.all() · players.get(name) · players.countThe people in the world. get ignores case and returns null if not found.

A player

name, x, y, connectedRead-only. Move someone with teleport.
speedWalking speed multiplier, 0–5 (1 is normal; 0 stands still). Stacks with Speed Boost purchases.
scaleDrawn size, 0.25–6. Visual only: collisions stay the same size.
colorBody colour like '#ff8800', or null for their normal colour.
titleText shown above their name (24 characters).
trail, frozen, hiddenRainbow trail on/off · can't move · invisible to others (they see themselves faintly).
teleport(x, y)Moves them (pushed out of any object they land in).
say(text)Shows a message on just their screen.
setAttribute(key, value)
getAttribute(key) · attributes		Your own data on a player: numbers, text or true/false. Up to 12 per player, keys A-Za-z0-9_. Everyone's browser can read them (client scripts: player.getAttribute, localPlayer.onAttributeChanged). setAttribute(key, null) removes one.

world

world.name / width / height / spawnRead-only info. world.setSpawn(x, y) moves the spawn point.
world.groundRead or set the ground colour ('#2f6b3a').
world.objects() · world.getObject(id)The trees, rocks, water and walls currently in the world.
world.addObject({ kind, x, y, w, h })Makes a new object. kind is tree, rock, water or wall. Max 300 objects in a world.
object: id kind x y w hSet any of them to move or resize it: rock.x += 10, or rock.set({ x: 5, y: 9 }). rock.remove() deletes it; rock.exists tells you if it is still there.
world.announce(text) · world.confetti(x, y)A message for everyone · confetti for everyone.

Events

onTick(fn)fn(dt) about 20 times a second while the world has players; dt is seconds since the last tick. Keep it quick.
ev.onServerEvent(fn)fn(player, ...args) when a client fires this event. player is who really sent it.
ev.fireClient(player, ...args)Send to one player's client scripts.
ev.fireAllClients(...args) · ev.fireOtherClients(player, ...args)Send to everyone / everyone but one player.

Client API CLIENT

camera

camera.zoom0.25–4 (1 is normal).
camera.follow(name?)Follow a player (default: yourself). This is the default camera.
camera.lookAt(x, y) · camera.x / camera.yPoint the camera at a spot in the world and leave it there. Read them to get where it is now.
camera.offset(x, y)Shift the view away from the target (e.g. look ahead).
camera.rotationDegrees.
camera.smooth0 snaps to the target; try 5–10 for a gentle glide.
camera.clamptrue (default) never shows past the world's edge; false lets it wander.
camera.shake(amount, seconds) · camera.reset()A quick screen shake · back to the default camera.

ui (on-screen HUD)

Every element has an id (calling again with the same id updates it). Options: anchor (top-left top top-right left center right bottom-left bottom bottom-right), x/y (pixels away from that edge, toward the middle), size, color, bg, width, height. Up to 40 elements.

ui.text(id, text, options)A line of text.
ui.bar(id, value, max, options)A progress / health bar.
ui.button(id, text, options, onClick)A clickable button.
ui.remove(id) · ui.clear() · ui.toast(text, seconds)Remove one · remove all · a short pop-up message.

input, localPlayer, effects

input.onKeyDown(fn) · onKeyUp(fn)fn(key) with a lowercase key name: 'w', ' ' (space), 'enter', 'arrowup'…
input.onClick(fn)fn(x, y) — where in the world the player clicked.
input.isDown(key) · input.moveEnabledIs a key held · set false to stop this player walking from their own keys and clicks (the server still runs everything real).
localPlayername x y color scale speed title frozen hidden attributes (read-only), getAttribute(k), onAttributeChanged(fn), walkTo(x, y). To change the player, ask the server with a RemoteEvent.
players · worldRead-only views of the other players and the world: players.all() / get(name) / count / onJoin / onLeave / onAttributeChanged; world.name width height ground spawn objects() onChanged(fn).
effects.confetti(x, y)Confetti, only on this screen.
effects.flash(color, seconds) · effects.floatText(text, x, y, color)A screen flash · text that floats up from a spot.
onFrame(fn)fn(dt) every animation frame (about 60 times a second).
ev.fireServer(...args) · ev.onClientEvent(fn)Send to the server's scripts · receive from the server (fn(...args)).

Limits

Scripts per world8, up to 20,000 characters each and 100,000 in total.
Server run timeEach event, tick or timer gets 50 ms. A script that goes over is stopped; after 5 overruns in a row all server scripts are turned off until you save again. Memory is capped at 32 MB. Up to 10 scripted worlds run at once.
Client run timeIf a client script gets stuck for about a second and a half, client scripts are turned off for that player. The game keeps running.
RemoteEvent dataUp to 8 values, plain data only (numbers, text, true/false, lists, objects), 4,096 characters, nested at most 6 deep. Clients can send about 30 a second each; the server about 200 a second per world.
SandboxScripts have no network, files, accounts or Seals. Client scripts run in a locked-down worker that can't make web requests. Use console.log to debug.
